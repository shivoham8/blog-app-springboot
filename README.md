# Blog App (Spring Boot)

A full-stack blogging platform built using Spring Boot, Thymeleaf, and JPA.

## Features

- User Authentication (Login/Register)
- Password Encryption (BCrypt)
- Create/Edit/Delete Posts
- Like System ❤️
- Comments & Replies 💬
- Search Functionality 🔍
- Pagination
- Ownership-based Authorization

## Tech Stack

- Java
- Spring Boot
- Spring Security
- Thymeleaf
- H2 Database

## How to Run

1. Clone repo
2. Run application
3. Open: http://localhost:8080
